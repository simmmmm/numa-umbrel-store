# Numa for umbrelOS

A community app store for [umbrelOS](https://umbrel.com) with [Numa Home](https://github.com/simmmmm/numa-home): your household's photographs on your own server.

To add it, open the App Store in umbrelOS, choose Community App Stores from the menu, and paste the URL of this repository.

Numa Home is published for x86-64 (amd64) only. It does not run on a Raspberry Pi yet.
